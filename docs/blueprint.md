# **App Name**: ArmarioIA

## Core Features:

- Mostrar Artículo: Mostrar artículos de ropa en formato de tarjeta con imagen, nombre, categoría y fecha de adición.
- Agregar Artículo: Permitir agregar un nuevo artículo de ropa a través de un formulario.
- Editar/Eliminar Artículo: Proporcionar funcionalidad para editar y eliminar artículos de ropa.
- Filtrar por Categoría: Implementar el filtrado de artículos por categoría utilizando un menú desplegable.
- Sugerencias de Estilo IA: Generar sugerencias de estilos basados en los artículos del armario del usuario. The LLM uses reasoning as a tool to decide when a particular article of clothing should be incorporated into the suggestion.

## Style Guidelines:

- Color primario: Cian desaturado (#77B5FE) para una sensación de calma y profesionalismo.
- Color de fondo: Gris claro (#F0F4F8) para asegurar que los artículos de ropa destaquen y den una estética limpia.
- Color de acento: Naranja suave (#FFB347) para resaltar elementos interactivos y llamadas a la acción.
- Combinación de fuentes: 'Belleza' (sans-serif) para titulares y textos cortos, 'Alegreya' (serif) para descripciones más largas o texto de cuerpo.
- Diseño basado en tarjetas para mostrar artículos en el armario digital.
- Usar iconos simples y elegantes para representar las categorías de ropa.
- Animaciones de transición sutiles al filtrar o editar artículos.
